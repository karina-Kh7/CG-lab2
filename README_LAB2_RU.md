# Лабораторная работа №2 — Камера и освещение (оценка 4)

**Вариант 11 — правильный икосаэдр.** Проект создан на основе исходников первой лабораторной из `vlk_start.zip`. Первая лабораторная не изменена.

## Что реализовано

1. База: камера с позицией, тремя углами поворота и FOV; один направленный источник; ambient; материал с альбедо, цветом блика и показателем блеска; освещение Блинна–Фонга во фрагментном шейдере; управление через ImGui.
2. Доп. №1: `set=0` для общих данных сцены (uniform, два storage buffer), `set=1` для материала и model/normal matrix.
3. Доп. №2: массив точечных источников, добавление/удаление, координаты, RGB, интенсивность, затухание `1 / distance²`.
4. Доп. №3: массив прожекторов, добавление/удаление, координаты, RGB, интенсивность, направление, два угла и плавная граница, затухание `1 / distance²`.

**Не реализуется доп. №4 (на 5):** визуальные маркеры источников и линии конусов.

Нормали икосаэдра генерируются процедурно в `application.cpp` посредством векторного произведения двух рёбер треугольника; нормали направлены наружу. Плоские грани требуют отдельных нормалей, поэтому вершины треугольников продублированы.

## Открытие в Visual Studio (Windows)

1. Распаковать **папку `CG-lab2`** независимо от `CG-lab1`.
2. Установить Vulkan SDK, в котором есть **`glslc.exe`**. Проверить в терминале `glslc --version`. Если не найден, добавить `Bin` Vulkan SDK в системную переменную `PATH` и перезапустить Visual Studio.
3. Открыть Visual Studio → **File → Open → Folder** → выбрать `CG-lab2` (где расположен `CMakeLists.txt`).
4. Подождать загрузки CMake/FetchContent. Нужен доступ к GitHub для загрузки зависимостей при первой сборке.
5. Собрать проект. CMake **обязательно** пересобирает оба шейдера GLSL в SPIR-V.
6. Запускать из каталога, где доступна папка `shaders` с файлами `.spv` (как в исходной первой лабораторной). Если приложение пишет `Cannot open shader`, проверьте рабочий каталог отладки.

## Где смотреть код на защите

- `source/application.cpp`: генерация нормалей и геометрии, буферы и дескрипторы, изменение параметров ImGui, матрицы камеры и объекта, отрисовка Vulkan.
- `shaders/icosahedron.vert`: перевод вершин и нормалей в мировые координаты.
- `shaders/icosahedron.frag`: направленный/точечный/прожекторный свет, Блинн–Фонг, закон обратных квадратов и плавные края конуса.

Вкладка `Point lights` управляет точечными источниками. Вкладка `Spot lights` управляет прожекторами. При `Outer angle > Inner angle` края переходят плавно.

**Важно:** проект подготовлен на уровне исходников; Vulkan SDK и компилятор GLSL в среде подготовки недоступны, поэтому запуск и компиляция в Visual Studio на Windows ещё требуют проверки. При ошибке сборки пришлите полный текст ошибки.
